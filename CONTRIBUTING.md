## Стек технологій та залежності

Проєкт побудований на базі **Next.js** (App Router). Перед початком роботи переконайтеся, що у вас встановлено Node.js.

Для коректної роботи проєкту необхідно завантажити залежності. Ми використовуємо такі ключові бібліотеки:
* **Фреймворк:** `next`, `react`
* **База даних:** `mongodb`, `mongoose`
* **Авторизація:** `next-auth`
* **Стилізація та UI:** `tailwindcss`, `lucide-react`
* **Візуалізація даних:** `recharts`
* **Тестування:** `vitest`

## Швидкий старт

**1. Встановіть залежності**
Після клонування репозиторію виконайте команду для завантаження всіх необхідних пакетів:

` ` `bash
npm install
` ` `

**2. Налаштуйте змінні середовища**
Створіть файл `.env` у корені проєкту. Для повноцінної роботи системи авторизації та бази даних вам знадобляться відповідні ключі (наприклад, `MONGODB_URI`, `GOOGLE_ID`, `GOOGLE_SECRET`, `NEXTAUTH_SECRET`). Зверніться до адміністратора проєкту для отримання тестових ключів.

**3. Запустіть сервер розробки**

` ` `bash
npm run dev
` ` `

Відкрийте [http://localhost:3000](http://localhost:3000) у своєму браузері, щоб побачити результат.
